How a request travels

Every call passes the same four guards before MySQL is ever touched.

BrowserjQuery AJAX sends the request with the x-api-key header.
checkKeyNo key or unknown key: 401. Revoked key: 403.
allowRolesWrong role for the endpoint: 403.
ownRecordOnlyA student asking for another id: 403.
spendRequestLimit used up: 429. Otherwise one request is counted and MySQL answers.

What the server answers

The status codes you will see in the Network tab.

200OKKey accepted, data returned.
401UnauthorizedKey missing or not recognised.
403ForbiddenRevoked key, wrong role, or someone else's record.
429Too many requestsThe key's request limit is used up.
500Server errorMySQL or the server has a problem.
